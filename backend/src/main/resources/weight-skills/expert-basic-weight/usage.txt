指标平台-专家基础权重

能做什么
评估具体指标对客户、业务连续性和合规的长期影响，为同一指标小类生成基础权重建议。适合首次评估及新增指标、定义实质变化时的增量评估。

怎么用
1. 在「AI 权重建议审核」点击「下载 Skills」，解压后在 Star Agent 导入本目录，保留 SKILL.md 和 references 目录。若平台只接受 ZIP，将本 Skill 单独打包。
2. 给智能体绑定指标平台目标环境的数据库 MCP。需要参数化查询、读取指标目录、既有建议及权重版本的权限，以及能原子写入两张建议中转表的事务工具。具体工具能力见 references/write-contract.md。
3. 首次可以这样输入：「请只分析指标大类 ID 123 下的缴费开通小类，先列出建议和依据，不提交。」核对后可改为「生成并写入待审核建议」。
4. 提交后，记下批次 ID，在指标平台「指标体系配置 → 检查 AI 权重建议」查看、修改、批准或驳回。

一般输入
系统 ID、指标大类 ID 或小类名、首次或增量评估、业务依据或资料链接、仅分析或提交。范围可省略，默认扫描已启用指标。建议默认有效 30 天。示例 ID 须替换为实际 ID。
