指标平台-月度动态权重

能做什么
对比最近两个完整自然月的指标采集数据和告警。熵权法衡量数据区分度，平台版 CRITIC 同时衡量波动和信息冗余。只有数据充分、两月方向一致且有长期业务影响证据时才提出调权建议。短期风险单独记录。

怎么用
1. 在「AI 权重建议审核」点击「下载 Skills」，解压后在 Star Agent 导入本目录，保留 SKILL.md 和 references 目录。若平台只接受 ZIP，将本 Skill 单独打包。
2. 给智能体绑定指标平台目标环境的数据库 MCP，配置参数化查询、历史数据读取和两张建议中转表的事务写入能力。若可用，绑定项目的历史观测查询接口和数值计算工具。
3. 首次可以这样输入：「请分析指标大类 ID 123 下的缴费开通小类，使用上一个完整自然月及对比月，仅输出分析。」确认数据口径后，可在月度任务中明确要求提交待审核建议。
4. 在指标平台「指标体系配置 → 检查 AI 权重建议」按「月度动态权重」查看批次。风险条目可查看或驳回，权重调整条目可由管理员预览和批准。

一般输入
系统 ID、指标大类 ID 或小类名、目标统计月、业务日历、业务变更依据、仅分析或提交。统计月可省略，默认北京时间上一个完整自然月，和再上一个完整月对比。范围可省略，默认扫描已启用指标。示例 ID 须替换为实际 ID。
