# 月度统计与建议规则 v1

按一个大类内同一小类分析。矩阵的行是对齐的观测日，列是同组指标。统计只用于衡量数据的区分度及信息冗余。业务影响依据另行判断。以下数值是保守的初始参数，需要变更时更新规则版本并在证据中记录。

## 1. 数据准入

- 使用北京时间上一个完整自然月和再前一个完整月。月间需使用相同定义、单位、来源和统计口径。跨越重大采集变更或明显季节事件时，记录原因并暂停数值建议。可用同季历史核对是否为季节性变化。
- 初版按日对齐。高频指标使用当天有效观测的中位数。业务本身是日汇总的指标直接用最新有效日记录。低于日频、缺数、口径冲突及未确认的异常输入不进入计算。保留有效零值，不把缺数填零。每个月至少 20 个组内共同有效日，且共同有效日不少于预期采集日的 80%。预期采集日按真实业务日历，未知时按所有自然日。两个月使用同一批可比指标，至少两项。覆盖不足或常量列被剔除后不足两项，停止该组数值建议。
- 每列把两个月有效值合并，计算第 5、95 百分位作为裁剪边界。百分位取排序后位置 `(N−1)q` 的线性插值。截尾后用同一上下界缩放至 [0, 1]。有已确认的业务方向时统一为值越大风险越高，原方向相反的列用 `1−z`。无方向依据或截尾后在任一周期内为常量的列仅保留业务说明。剔除这些列后重新核对共同有效日。保留裁剪行数，原始数据仍用于异常解释。

## 2. 计算两个统计权重

每个月使用该月共同有效日，两个算法分别归一为合计 1。分母接近零（绝对值小于 `1e-12`）时标记该算法不可用。

**熵权法**。对指标 i 的归一化观测 `z[t,i]`，计算 `p[t,i] = z[t,i] / Σ_t z[t,i]`，`e[i] = −Σ_t p[t,i] × ln(p[t,i]) / ln(n)`。其中 `0 ln 0 = 0`，`n` 是本月共同有效日数。区分度 `d[i] = max(0, 1−e[i])`，得到 `E[i] = d[i] / Σd`。分布越不均匀，该列可能越能区分观测日，需结合裁剪和异常记录核对。

**平台版 CRITIC**。计算 `σ[i]`（归一化观测的总体标准差）和同月对齐后的 Pearson 相关系数 `r[i,j]`。用 `Craw[i] = σ[i] × Σ_(j≠i)(1−|r[i,j]|)`，再得 `C[i] = Craw[i] / ΣCraw`。原始 CRITIC 使用 `1−r`。这里使用 `1−|r|`，让同涨同跌和反向重复两种情况都受到冗余折扣。这是本平台的规则选择。相关性可用来提示信息重复，判断重复时还需看业务含义。

只有两种算法在两个月均可用时才产生数值建议。当前月统计占比 `S[i] = (E[i] + C[i]) / 2`，对比月同算。任一方法不可用时保留能算出的诊断结果。

方法来源。[Shannon 熵原文](https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf) · [CRITIC 原论文](https://doi.org/10.1016/0305-0548(94)00059-H)

## 3. 将统计结果约束为可审核建议

1. 读取整组已应用的基础权重，按写入契约计算当前占比 `w[i]`。设参与统计的指标当前占比之和为 `W`。若 `W=0`，暂停该组数值建议。分别将两个月的 `E[i]` 和 `C[i]` 与 `w[i]/W` 比较，四个差值须同为正或同为负，绝对值小于 `1e-12` 视为持平。任一方向相反或持平，则本项不提数值变更。方向相同也须有独立的持续业务影响证据，例如服务覆盖变化或正式合规要求变化，且证据支持同一方向。
2. 统计信号占 20%，当前基础占比占 80%。对通过上一项的指标，候选值 `candidate[i] = 0.8 × w[i] + 0.2 × W × S[i]`。以百分点表示候选差值，先限制在 ±5，向零截取到整百分点。绝对变化不足 1 个百分点则保持现状。
3. 按平台审核口径预演全组。把准备提交的目标占比固定，剩余比例按未选指标的原始系数分配，使用写入契约的余数规则。如果合计不能达到 100%、任何成员变化超过 5 个百分点，或任一未选指标被动变化超过 1 个百分点，依次尝试将第 2 步的整百分点差值统一乘以 0.75、0.50、0.25 后向零取整，每次重新预演。归零项移回未选组；仍不满足或均归零时暂缓数值建议。审核台仍展示所有联动变化。
4. 仅有短期风险、告警上升、处置变慢、突发波动或统计方向不稳定时，按需要提交 `current_risk`，保持当前占比。长期重要性证据与模型方向冲突时，将依据留给人工讨论。稳定且重要的指标即使很少波动，也可保留其原有权重。
5. 建议用计算工具复算，保存 `rule_version`、两个周期及覆盖、截尾边界、两个周期的 `E/C/S`、当前与候选占比、应用的限幅和全组联动、业务证据出处。计算工具不可用时，提交可验证的风险分析或返回缺口，暂缓数值建议。

例如当前三项占比为 40% / 30% / 30%，合成统计占比为 60% / 20% / 20%。第一项有独立的长期影响证据时，候选为 44%。其余两项将降到 28%，超过未选联动上限。缩小候选变化后可得到 42% / 29% / 29%，审核人仍需确认整组变化。
